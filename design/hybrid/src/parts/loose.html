Loose ends

What an agent has handed you to do, or is waiting on you to answer, kept with its chat until you've done it. Drawn 12 Oct 2026 for the owner's approval.

Agents end turns with things only you can do: make the forum accounts, send the drafted emails, take a photo of the meter, answer which forums to post on. In a long chat these scroll away. A loose end keeps each one with its chat until you tick it off. Agents file them over CONTROL's MCP; nothing is guessed from a reply. Each chat has its own. The mail icon at the far right of the panel's tab row opens this chat's, and a chat with any open shows the count on its card, so you can see what you owe without opening every chat. Nothing pings: needs-you stays for what is blocking a turn right now.

LE1The popover

The icon opens a popover hung from it, over whatever view the panel shows; it doesn't switch the panel. ⌘E opens and closes it too. Each loose end is one line in the agent's words and a reason under it, with the turn it came from. A click on the turn scrolls the thread to it. An agent can attach one action: a link (Open), a file (Reveal) or a command (Copy). The box ticks it Done; the × on hover dismisses it, for one you won't do. The agent can close one itself when it can see it's done, for instance once you've sent the photos in the chat.

LE2On the cards

Any chat with a loose end open shows the mail glyph and the count on line 2, just before the tokens. A click on the count opens that chat with its popover up. Settled chats keep the mark in the Settled fold. A long chat name gives way to it; on line 3 the state words did, and on line 1 the project name (owner's pick, 12 Oct).

LE3Settling

Every way of settling a chat that still owes you asks first: the menu, ⌘⇧S and a drop on the Settled fold. Settle keeps the loose ends with the chat, and its card keeps the mark in Settled. Esc and Cancel leave it where it was. A chat with nothing open settles as it does today.

LE4The phone

The phone has no panel, so the chat's header carries the mail item beside its list item, with the count as a badge. It opens a sheet with the same list, at half height first, and everything works there: tick, dismiss, Open and Copy. The phone's own reskin is not designed yet (HANDOFF §12); the header items are native (SF Symbols envelope and list.bullet), so only the sheet is CONTROL's own drawing.
