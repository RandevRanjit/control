# Saved logins

The desktop app's browser can sign in to a site for you, in your tabs and in the tabs your agents
drive.

On the site's sign-in page, open the browser's **⋮** menu and choose **Save login…**. You can also
add one under **Settings → Integrations → Logins**; use the address of the sign-in page itself, which
for a university or work account is often not the site you were heading for.

CONTROL fills in and sends a login only on the exact `https` address it was saved for, once per page,
and never in Incognito. Agents use it without asking. They are told when to wait for it, and a code
sent by text message is still yours to type.

If a site asks again straight away, CONTROL takes it that the login was turned down, marks it
**Turned down** and stops using it. Choose **Update** to change the password or **Retry** to try the
same one again.

Passwords are encrypted with a key in your Mac's Keychain and can't be shown again, only replaced.
Saved logins stay on this Mac: a browser tab that runs while the desktop app's window is closed
doesn't use them.
