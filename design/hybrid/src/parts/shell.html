Shell

T3 as it is, three ways to combine it with Bloom, and D, version 1. Every window is 1512 × 945, drawn at 1:1 and scaled to the column.

A window is five decisions: the sidebar, the head of the conversation, the centre, the composer and the panel. T3 and Bloom disagree on all five. A takes T3's answer to each and paints it in Bloom. B takes Bloom's answer to each, the window you confirmed in section 06, and maps T3's features into it. C picks per decision, and the table says which side wins where and why. D is what you built from them over twelve passes, and it is version 1: S6 is the window, S7 its panel tab by tab.

S1T3 Code as it is

The baseline, drawn from T3's source at the fork point. The sidebar is one flat list of cards, newest first: the folder on line 1 with a status label at the right, the chat's title on line 2, the branch on line 3. Pinned chats lead the list, snoozed and settled ones drop to shelves at the bottom, and archive is a menu action with no shelf. The head is a breadcrumb, folder / title, with three toggles: details, the shell drawer (⌘J) and the right panel.

The centre is the conversation already. Your messages are bubbles on the right; each turn's tool calls are a work log of one-line rows with an icon each, folding to "Worked for 18s" when the turn ends. The composer carries the model, effort and access pickers, and a strip under it holds where the turn runs: this folder or a new worktree, and the branch. The panel holds tabs you open, rename and close. No status label moves: working is a dashed ring and a ticking time.

S2A · T3's frame, Bloom's paint

T3's geometry kept whole and painted with Bloom: Field and Night, Regrade for the chrome and Plex for anything you could paste, the session's name in Plex on line 2, and tone steps where T3 draws its 1 px rules. Where T3 puts a status label, A puts Bloom's state: a bead bar and the colourless lamp at the right of line 1, with the state words joining the branch on line 3.

It is the cheapest option to build, because every T3 component keeps its layout and takes new tokens. What it gives up is most of what you confirmed in section 06: the cards become T3's icon rows, your prompt becomes a bubble, the head says the title the selected row already says, and a three-line card holds a chat in 82 px where Bloom's row takes 42.

S3B · Bloom's frame on T3's engine

Section 06 as confirmed: the sidebar runs the full height and holds the lights; the head says only the path, over the one full state bar; the centre is the conversation, with every read, write, error and agent as a card; the panel is a strip of icons. T3 brings the engine underneath, so the cards come from T3's own event stream instead of a mod watching a TUI, and Send goes straight to the agent instead of pre-typing into tmux.

T3's six panel views land in Bloom's five icons. Files becomes Folder. Diff and Pull request become Git, with Graph | Diff as its mode and the PR as a row at its top. Browser and Terminal keep their names. Device (T3's simulator mirror for mobile work) has no tab: it opens from the command palette when a project has a simulator. Outputs is Bloom's alone: the files a chat produced.

S4C · per decision (recommended)

Bloom's sidebar, head and centre, because you confirmed them and nothing T3 does there is better at a glance. T3 wins three things Bloom never had to solve, because v1 drove Claude's TUI rather than the agent itself.

The composer's controls. Model, effort, mode and access are now settings CONTROL sends with each turn, so they are real controls in the composer, in Bloom's material, with the context line beside Send. The branch strip. Where the next turn runs, this folder or a new worktree, and on which branch, is T3's strip tucked under the composer; in v1 it lived nowhere, because Claude chose. The shell drawer. T3 puts the app's own shells in a drawer under the conversation (⌘J), so a build log and the chat that caused it are visible at once; the panel keeps Browser and Git for the right-hand side. The sidebar carries the Claude update note and its button, from v2's decisions.

S6D · version 1.1

Started as your scratchpad on A and settled over twelve passes. The sidebar is A's three-line cards inside groups › folders › chats: line 1 the project, the bead bar and the lamp; line 2 the chat and the tokens it has processed; line 3 the state, then git, then the model and a five-bar effort meter. C's update note sits under the search; Snoozed and Settled (archive merged into it) and 5H / 7D sit at the foot; the stair logo is centred beside the settings button.

The head says what the chat loads. The centre is a thread: each prompt on a full-width band with →, the tool calls stacked (the last five, click for the rest) one step in and written like S2's work log, each with a quiet bead (dim when done, blinking while it runs, red when it failed) under a lamp for the stack (the working ring, then the tick), and the reply after ↳; one dashed line in whole dashes joins the prompt's arrow to the last reply's. The composer is A's, with the strip under it giving the context as Chat, Free and Compacts at. The panel is B's, flat, with its five tabs live. Every number and rule is in design/hybrid/HANDOFF.md; the CSS is in design/hybrid/v1.2/ (1.1 stays in v1.1/, and 1.0, with the Hue trace, in v1/).

S7D's right panel, tab by tab

The rest of the panel, at 1:1 in D's flat panel. Outputs is everything this chat made, newest first, grouped by turn, with the picked one rendered underneath: a Markdown report here (F28, F30). Folder is the session's worktree as a tree with git's marks, and the picked file open at its right under its own tabs, at 720 so both fit (F31). Browser is the live dev server, with the pick tool on button.cta and Add putting it in the composer as a draft, never sent (F36, F37). Terminal is the session's own shells, tab 2 running bun dev. Git is S6's.
